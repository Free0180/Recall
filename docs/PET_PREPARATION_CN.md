# PET 全科备考工作台

入口：登录后点击底部“备考”。不接入 AI，无需新增付费服务或数据库表。

## 语法与写作小课

“备考 → 语法与句子”现有 11 节系统小课：句子完整性、-ing 与 to do、时态对比、过去习惯与计划、条件句、转述与间接问句、定语从句、被动、连接词、比较与数量、情态动词。

“备考 → 写作表达课”现有 6 节小课：邮件安排、理由与例子、建议和询问、文章段落、故事叙述、修改检查。也可从“写作 → 先学写作表达课”进入。

每课有中文讲解、例句拆解、常见错误对照、2 道选择题及解析、独立造句、段落运用、参考示范、自查要点、原稿保留、手工点评和修改对照。共 34 道新增学后客观题，另有 17 个造句任务和 17 个段落/写作任务。课程练习不冒充首次水平诊断，也不自动评价开放式答案。原有综合小测继续保留。

输入按账号保存到本机，包含在“家长复盘 → 导出备考备份”中。旧版本没有课程字段的备份仍可读取。恢复备份会整体替换备考记录，请先保存当前备份。

点击“导出本课点评材料”，会同时带上题目、独立原稿、已有点评和修改稿，发送到对话后手工点评。参考答案不作为开放式表达的唯一正确答案，不提供“背某一句即可得分”的承诺。

课程范围参考剑桥教师资料，教学内容与例句为本项目原创：

## 手工点评流程

1. 孩子独立完成，记录真实用时及得到的帮助。
2. 写作在写作页导出点评材料并另附照片；口语导出任务与点评单并另附手机录音；句子练习可导出 TXT。
3. 把材料发到当前对话。作文照片不能用来判断发音，缺少音频时不评价口语发音。
4. 收到点评后粘贴到对应记录。写作还有修改稿和复查栏；其他记录可标记“已完成复查”。

## 保存与备份范围

- 备考数据按登录用户名存入本机浏览器，不随现有 Supabase 词汇进度同步。
- “家长复盘”导出的 JSON 包含计划、短语人工标记、客观题作答和手工记录。恢复仅接受当前账号的合法格式，会确认后替换当前备考记录。
- 写作原稿与照片使用原有写作备份。录音由家长保管，选择文件只用于临时试听，离开模块需重新选择。
- 未提交的客观题、拼写输入、未保存的手工表单及迁移句子草稿不会自动保存。提交、保存或导出后再离开。
- 首次诊断不因重做而覆盖；错题列表按每组最近一次提交更新。
- 检测到其他标签页已经修改记录时拒绝继续保存，刷新后重试。请避免在多个标签页同时编辑。
- 单账号最多 500 次客观题提交、300 条手工记录；到达上限会提示，不静默删除旧记录。

周末默认按周六、周日各 120 分钟安排；若周末总共两小时，请改为每天 60 分钟。具体考试日期默认留空，不虚构日期。漏做任务不会自动累加到次日。

## 今日任务与外部 AI 点评

登录后默认进入“备考 → 今日任务”，按清单进入相应模块，提交后点击“返回今日任务”。

- 前期：每天词汇和听力，语法与写作表达课轮换，阅读与口语穿插，周末完整写作。
- 后期：每天保留词汇，增加阅读、听力、写作、口语分科主练和错题复盘。现有缩短练习不能代替完整模考。
- 默认目标为 2027 年 3 月，后期从 2027 年 1 月 1 日开始。家长可在“阶段与时间设置”调整切换日期、强制选择阶段或调整每天时间。
- 新设置用于新一天；未作答且没有备注、提交或快照的当天可重新安排。任务也能逐项替换、调整时间或暂缓。漏做不自动累积，可查看历史日期并手动安排补做。
- 客观题提交、课程练习及原稿提交、完整写作原稿提交、词汇任务和听写提交会在返回清单后核对。仅打开页面不会完成。口语、自有材料、错题复盘等填写学习记录后手动确认。

### 导出和回传

1. 点击“导出当天学习材料”，得到 TXT，包含题目、实际作答/草稿、完成状态、学习记录和回传 JSON 模板。未完成任务也明确标注。
2. 将 TXT 发给外部 AI，请它按文件末尾模板返回完整 JSON。照片、录音另附；只凭文本不能评判发音。超过汇总容量的材料会明确标注截断，需要另附模块完整导出。
3. 在同一天的“粘贴外部点评 JSON”粘贴返回内容，或选择 JSON 文件。
4. 点击“校验并预览点评”，核对内容后“确认导入点评”。系统核对账号、日期、导出编号和所有任务编号；不匹配会拒绝保存。
5. 点评保存在对应导出版本下，原稿和完成状态不被修改。家长核对建议后手动调整学习任务。无需 API Key，也没有应用内 AI 请求。

导出版本保存固定材料快照，再做题不会改变旧快照。每天最多 3 份，可重新下载；最多保存 90 天任务。接近容量上限会停止保存并提示备份，不静默删除。历史任务可以先下载完整备份再删除。

每日任务、快照和导入点评包含在“家长复盘 → 导出备考备份”的 JSON 中，仍按账号保存在本机浏览器。换设备请备份和恢复；写作照片、录音仍单独保管。外部 AI 点评需要家长核对，不等同于正式考试评分。
