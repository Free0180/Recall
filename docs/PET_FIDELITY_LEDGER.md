## 文案差异

- 概念稿只展示一句简短重音提示。实际实现增加了每个词的拼读规律说明，便于家长和学生理解。
- 平板概念稿写作“今日 3 / 10”。空白数据首次打开时实际显示“今日 0 / 10”，学习后实时变化。
- 实际词库使用 30 个原创整理的 B1/PET 常用词条与例句，不直接复制受版权保护的官方教材内容。

## 有意调整

- 手机端取消概念稿中的返回按钮。第一版是五个一级页面，没有需要返回的上级页面，保留按钮会造成无效操作。
- 手机端内容密度略高于概念稿，使三个评价按钮和底部导航在 430x932 首屏内可操作。
- 平板端将学习内容限制在 1180px，避免在高分辨率屏幕上出现过长行宽。
- 成品不使用概念稿中的情绪脸图标，改用同一套 Lucide 线性图标，保证图标风格一致。
