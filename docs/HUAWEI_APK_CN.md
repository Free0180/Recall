# 华为 Pad APK 说明

## 功能

- 应用名称：PET词汇精读
- 支持华为 Pad 上的独立桌面图标和全屏显示
- 支持网页返回
- 支持选择 Word、PDF 和音频文件
- 固定加载 `https://free0180.github.io/Recall/`
- 网站内容更新后，APK 中会自动显示最新内容

## 下载

1. 打开 GitHub 仓库的 Actions 页面。
2. 选择 `Build Huawei Pad APK`。
3. 打开最新的绿色成功记录。
4. 在页面底部下载 `PET-Vocab-Huawei-Pad-APK`。
5. 解压后得到 `PET-Vocab-Huawei-Pad.apk`。

## 安装

1. 将 APK 传到华为 Pad。
2. 在文件管理中点击 APK。
3. 按系统提示允许当前来源安装应用。
4. 完成安装后，从桌面打开“PET词汇精读”。

## 注意事项

- 这是供本人和指定用户安装的测试版，不用于应用市场发布。
- APK 需要联网完成首次加载和 Supabase 登录。
- APK 内的学习进度与华为浏览器中的进度相互独立。
- 卸载 APK 会同时删除保存在 APK 内的本地学习数据，请先导出重要内容。
